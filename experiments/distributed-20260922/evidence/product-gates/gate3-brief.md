## Why these keys exist
§28.5 of the spec: a provider's ignored/generated build products (`dist`, generated types, bundles) must be declared so they can be transported to a consumer's node. `buildOutputs` declares, per package, the literal paths (files or folders, relative to the package folder) a successful build produces and its consumers or its own publish stage need. `buildPlatforms` declares which node platforms (`os/arch`, Go's GOOS/GOARCH spelling) may run the package's build and publish tasks; empty means any node. Nothing consumes them yet in this gate: this gate is model + ladder resolution + validation + discovery-time overlap refusal.
